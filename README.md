Algoritmo de Compressão RLE em C
Este repositório contém a minha implementação do algoritmo de compressão e descompressão de imagens sem perdas baseado em Run-Length Encoding (RLE).

Nota: Este código foi desenvolvido como parte do trabalho da disciplina de Fundamentos de Programação da UTFPR. Por questões de integridade acadêmica e para respeitar os direitos autorais do código base fornecido pelos professores, estou disponibilizando apenas a lógica central (compressão e descompressão) desenvolvida exclusivamente por mim. As funções auxiliares de leitura e gravação de bitmaps foram omitidas.
